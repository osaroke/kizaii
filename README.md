# RACK NOTE

手持ちの音源・プラグインを管理する、iPhone 向けの1ファイル完結の Web アプリ。

## できること

- 音源・プラグイン・楽器（実機）をフォルダ（EQ、コンプ、リバーブなど）に分けて登録
- 重さ（軽い／ふつう／重い）と役割タグ（普段使い・味付け・バス・マスターなど）で絞り込み
- VST2 のみの製品に警告バッジ
- 「今日使った」の記録と、60日以上使っていないもののおすすめ（アイデアタブ）
- 表示中のプラグインを Cubase のコレクション作り用にテキストで書き出し
- 採用・非表示・削除の理由を製品ごとに📌で記録
- 「表示中 / 隠す / 削除済み」の3つに分けて管理（Cubase の非表示設定と合わせる用）
- 製品ごとに「使い方のアイデア」をメモ
- 所持・欲しい・体験版の状態管理、お気に入り
- 手持ち一覧のプリセット取り込み（設定 → プラグイン一覧）
- JSON で書き出し・読み込み（バックアップ用）

## 使い方

1. `index.html` をブラウザで開く（GitHub Pages で公開すると iPhone からも使える）
2. 初回はホームの 📥 バナーを押して、手持ち一覧を取り込む
3. すでにデータがある場合は 🧹 バナーで整理結果を反映する

## データについて

- データはブラウザの localStorage（キー: `racknote.v1`）にだけ保存される
- サーバーには何も送らない
- 端末やブラウザを変えるとデータは引き継がれないので、設定画面の「書き出し」でときどきバックアップする
- 別の場所（Claude の Artifact 版など）から移すときは、「JSONをコピー」→ こちらで「貼り付けて読み込み」

## GitHub Pages で公開する手順

1. このフォルダの中身（`index.html`、`README.md`、`.nojekyll`）をリポジトリの直下に置く
2. リポジトリの Settings → Pages → Branch を `main` / `/ (root)` にして保存
3. 数分後に表示される URL を iPhone の Safari で開き、共有 → 「ホーム画面に追加」
